# Financial Movement Report — ReportKit example

This example reconstructs the supplied one-page hotel financial movement report using **ReportKit components**, with all financial data and totals supplied explicitly in `data.py`.

## Files
- `data.py`: bilingual branding, filters, four transactions, payment-method summary and precomputed totals.
- `styles.py`: styling tokens.
- `report.py`: component tree and `HtmlExporter` invocation.
- `logo.png`: extracted reference branding asset.
- `reference_preview.html`: standalone visual reference from the previous design pass; **not** generated by ReportKit.

## Run

From the ReportKit project root, install the library and dependencies, then run:

```bash
python -m examples.financial_movement.report
```

This writes `examples/financial_movement/reportkit_output.html`.

**Integration note:** The component and exporter calls follow the API designed in this conversation. The actual ReportKit package source is not supplied here, so this integration has not been executed against the real project. Check `Style` accepted properties, `Image.src` handling of file URIs, and `HtmlExporter` constructor signature against your implementation. If a renderer lacks support for bilingual table headers or 3-column hotel branding, extend the generic renderers/styles instead of introducing report-specific HTML in the library.

## Design target
A4 portrait, bilingual three-column hotel branding, registration/tax identity strip, bilingual title and filters, 9-column transaction table, payment-method summary, print metadata and page number. Reference original: `financial-movement-2026-11-20 (1)(1).pdf`.
