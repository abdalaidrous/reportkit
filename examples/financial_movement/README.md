# Financial Movement Report — ReportKit example

This example reconstructs the supplied one-page hotel financial movement report using **ReportKit components**, with all financial data and totals supplied explicitly in `data.py`.

## Files
- `data.py`: bilingual branding, filters, four transactions, payment-method summary and precomputed totals.
- `styles.py`: styling tokens.
- `report.py`: component tree and `HtmlExporter` invocation.
- `logo.png`: extracted reference branding asset.
- `reference_preview.html`: the target design (colors, borders, layout); **not** generated by ReportKit.

## Run

From the ReportKit project root, install the library and dependencies, then run:

```bash
python -m examples.financial_movement.report
```

This writes `examples/financial_movement/reportkit_output.html`. Add `--pdf` to also write `reportkit_output.pdf` through `PdfExporter` (needs the optional WeasyPrint dependency, or run it in Docker as described in `CLAUDE.md`).

Page numbers are print margin boxes: they appear in the browser print preview (Ctrl+P) and in PDFs printed from the HTML, not in the normal screen view.

## Custom table cells

A row value may be a plain value, formatted by its column, or a `TableCell` with child components:

```python
TableRow(values={
    'date': TableCell(children=[Text(value='14/11/2026'), Text(value='12:47 AM', style=Style(font_size=9, color='#777777'))]),
    'amount': 500,
})
```

Children keep their own styles; the table only stacks them. A `TableCell` takes either `value` or `children`, not both.

## Design target
A4 portrait, bilingual three-column hotel branding, registration/tax identity strip, bilingual title and filters, 9-column transaction table, payment-method summary, print metadata and page number. Reference original: `financial-movement-2026-11-20 (1)(1).pdf`.
